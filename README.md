# Atividade de Git e GitHub

Repositório desenvolvido para a atividade avaliativa da disciplina de Prototipagem.

## Objetivo

O objetivo deste projeto é praticar o uso de Git e GitHub para controle de versões e organização do desenvolvimento de um projeto.

## Integrantes

- Elias Rodrigues de Oliveira

## Conteúdos trabalhados

Durante a atividade serão praticados conceitos como:

- repositório;
- commits;
- histórico de versões;
- push e pull;
- colaboração utilizando GitHub.
