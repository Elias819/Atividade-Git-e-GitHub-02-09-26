# Git

Git é um sistema de controle de versão utilizado para registrar e acompanhar alterações realizadas em um projeto.

## Comandos básicos

### git init

Inicia um repositório Git.

### git status

Mostra o estado atual dos arquivos do projeto.

### git add

Adiciona alterações para serem incluídas no próximo commit.

### git commit

Registra uma versão do projeto no histórico.
