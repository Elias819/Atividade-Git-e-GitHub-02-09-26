# Branches

Um branch é uma linha independente de desenvolvimento dentro do mesmo repositório.

Ele permite desenvolver ou testar alterações sem modificar diretamente o branch principal do projeto.

## Main

O branch main representa, por convenção, a linha principal e estável do projeto.

## Merge

Merge é o processo utilizado para juntar as alterações de um branch com outro.

## Conflito de merge

Um conflito pode acontecer quando o mesmo trecho de um arquivo é alterado de formas diferentes em branches distintos.
