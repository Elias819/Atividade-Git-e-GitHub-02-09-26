# Colaboração no GitHub

O GitHub possui recursos que facilitam o trabalho em equipe e a organização das alterações de um projeto.

## Issue

Uma Issue pode ser utilizada para registrar uma tarefa, um problema, um bug ou uma ideia relacionada ao projeto.

## Pull Request

Um Pull Request é uma solicitação para que as alterações feitas em um branch sejam revisadas e posteriormente mescladas ao projeto principal.

## Fork

Um Fork cria uma cópia independente de um repositório de outra pessoa na própria conta do GitHub.
