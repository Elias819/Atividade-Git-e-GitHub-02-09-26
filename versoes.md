# Versionamento

O versionamento permite identificar pontos importantes do desenvolvimento de um projeto.

## Tag

Uma tag marca um commit específico como um ponto importante no histórico do projeto.

Exemplos de tags:

- v1.0
- v1.1
- v2.0

## Release

Uma Release representa uma versão oficial e pronta para uso de um projeto no GitHub, normalmente associada a uma tag.

Ela também pode apresentar informações sobre as alterações realizadas naquela versão.
